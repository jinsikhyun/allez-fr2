# Allez! 🥐 — 교프어II 복습 앱

등하굣길 3분 복습용 앱. 폰 브라우저로 배포 주소를 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요 (오프라인 OK).

- 새 수업자료(PDF)는 `../강의자료/`에, 필기는 노션 `26-2 / 필기 및 자료 / 교양프랑스어II`에 올리면
  **화·수·목 23시**에 자동으로 문제가 추가돼요 (Mac + Claude 앱이 켜져 있을 때. 꺼져 있었으면 다음 실행 때).
- 급할 땐 Claude에게 "복습앱 업데이트해줘".
- 학습 기록은 폰에만 저장돼요 → ⚙️ 내 기록 › 백업 코드로 옮기기.

구조와 업데이트 절차는 `CLAUDE.md`, 문제 작성 규칙은 `CONTENT_GUIDE.md`.
